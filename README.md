# CrossCopy

**一台电脑复制，另一台直接粘贴；一套键鼠，自然穿越多台电脑。**

CrossCopy 是一款面向 macOS 与 Windows 的轻量级局域网协作工具。它让你在多台电脑之间传递文字、文件和文件夹，也可以像使用扩展屏一样，让鼠标从一台电脑自然穿越到另一台。

无需填写 IP 地址或端口，无需把文件上传到云端。第一次配对完成后，设备再次上线即可自动连接。

[下载最新版](https://github.com/JonesLiang/cross-copy/releases/latest)

## 主要功能

### 跨设备复制粘贴

- 支持文字、单个文件、多个文件、文件夹和压缩包
- 使用独立的跨设备快捷键，不影响日常的 `Ctrl+C` 和 `Ctrl+V`
- 默认使用 `Ctrl+Shift+C` 复制、`Ctrl+Shift+V` 粘贴
- 快捷键可以在设置中修改
- 大文件传输拥有独立进度提示，主窗口关闭后仍可继续
- 一台电脑复制后，可在其他已授权设备上粘贴

### 一套鼠标控制多台电脑

- 鼠标移动到屏幕边缘，即可自然穿越到另一台电脑
- 穿越时保持鼠标在屏幕中的相对位置
- 支持左键、右键、滚轮滚动和滚轮按下
- 支持触控板滚动
- 支持多显示器、扩展屏和镜像屏场景
- 可在设置中拖动排列电脑的逻辑位置
- 可为不同来源设备单独调整鼠标灵敏度
- 支持 `Ctrl+Shift+数字` 快速将鼠标切换到指定电脑
- 任意一方关闭鼠标共享后，双方立即停止穿越
- 本机物理鼠标始终拥有优先控制权

### 多设备协作

CrossCopy 不局限于两台电脑。家里、工作室或办公桌上的多台 macOS 与 Windows 设备可以组成可信设备组：

- 新设备加入后，可与组内已授权设备协作
- 每台设备都可以单独管理其他电脑的剪贴板和鼠标权限
- 可以决定自己的内容允许发送给谁
- 未获得权限的设备不能接收内容，也不能参与鼠标控制
- 当多台电脑尝试控制同一目标时，最后发起控制的设备获得控制权，其他设备不受影响

## 小巧，但不牺牲体验

CrossCopy 将常驻负担控制在尽可能低的范围内：

- 空闲时自动进入低功耗状态，减少网络、处理器和电量消耗
- 触发快捷键或鼠标穿越时快速唤醒，无需等待手动重连
- 大文件传输不会一次性占满内存
- 局域网内直接传输，速度主要取决于你的 Wi-Fi、有线网络和磁盘性能
- 鼠标移动针对低延迟和连续性优化，跨屏操作更接近本地体验
- 未使用鼠标共享时，不会持续处理鼠标事件
- 可关闭主窗口并继续在系统托盘或菜单栏后台运行
- 支持开机启动、浅色模式和深色模式

## 安全与隐私

你的内容属于你。CrossCopy 默认只服务于同一局域网内的可信设备：

- 文件和文字无需经过云端中转
- 首次连接使用短时配对码确认双方身份
- 配对完成后，日常使用不需要反复输入密码
- 设备之间的内容和控制数据会受到加密保护
- 每台设备均可独立关闭剪贴板或鼠标权限
- 接收到的内容保存在 CrossCopy 待粘贴区，不会长期覆盖系统剪贴板
- 诊断日志不会记录配对码、设备密钥、剪贴板文字内容或完整文件路径

请只在自己信任的局域网中完成首次配对，并妥善管理已配对设备。

## 快速开始

### 1. 安装

前往 [Releases](https://github.com/JonesLiang/cross-copy/releases/latest) 下载对应系统的最新版：

- **macOS：** 下载 macOS 安装包，将 CrossCopy 拖入“应用程序”后打开
- **Windows：** 下载 Windows 安装程序并按提示完成安装

### 2. 首次配对

1. 确保两台电脑连接到同一个局域网
2. 在其中一台电脑上生成配对码
3. 在另一台电脑上输入配对码
4. 配对成功后，设备会被记住，后续开机无需再次输入

整个过程不需要填写 IP 地址、端口号或其他网络参数。

### 3. 开始使用

- 按 `Ctrl+Shift+C` 将当前文字或文件复制到 CrossCopy
- 在另一台电脑按 `Ctrl+Shift+V` 粘贴
- 在设置中开启鼠标共享并排列设备位置，即可从屏幕边缘穿越
- 使用 `Ctrl+Shift+M` 快速开启或关闭鼠标共享

所有快捷键都可以在设置页面中调整。

## 系统权限

### macOS

首次启用全局快捷键或鼠标共享时，macOS 会要求授予 CrossCopy“辅助功能”权限。授权后无需每次重复确认。

请从“系统设置 → 隐私与安全性 → 辅助功能”中允许 CrossCopy，并确保运行的是“应用程序”文件夹中的版本。

### Windows

Windows 防火墙首次询问时，请允许 CrossCopy 在专用网络中通信。企业 Wi-Fi、访客网络或开启设备隔离的路由器，可能会阻止电脑之间互相发现。

## 后台运行与自动更新

关闭 CrossCopy 主窗口不会结束正在进行的传输，应用会继续在菜单栏或系统托盘中运行。你可以随时从托盘图标重新打开、暂停功能或退出程序。

CrossCopy 支持应用内检查更新、下载进度展示和一键安装。更新包在安装前会进行安全校验。

## 遇到问题

如果设备无法发现、传输失败或鼠标体验异常，可以在应用底部点击“导出诊断日志”。日志会保存到系统下载目录的 `CrossCopy` 文件夹，方便在反馈问题时一并提供。

提交问题前，建议确认：

- 所有设备均已升级到最新版
- 设备位于同一局域网，且没有开启访客网络或设备隔离
- 系统防火墙允许 CrossCopy 通信
- macOS 已授予辅助功能权限
